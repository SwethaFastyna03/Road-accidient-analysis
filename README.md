# Road Accident Analysis Project

## Project Overview
This project focuses on analyzing road accident data to understand patterns and insights such as accident severity, road conditions, weather impact, time-based trends, and more using Python data analysis tools.

## Objectives
- Analyze accident severity distribution
- Identify high-risk road conditions
- Understand impact of weather on accidents
- Find accident patterns by time and day
- Visualize insights using graphs

## Tools & Technologies Used
* Python 
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset
- Dataset is sourced from Kaggle.
- Kaggle Dataset Link:
 **dataset**:https://www.kaggle.com/datasets/xavierberge/road-accident-dataset?resource=download

## Visualizations
- Accident Severity → Bar Chart
- Weather Conditions → Bar Chart
- Accidents by Hour → Line Chart
- Speed Limit → Histogram
- Road Type → Horizontal Bar Chart
- Accidents by Day of Week → Bar Chart
- Correlation Matrix → Heatmap

## Key Insights
- Certain weather conditions increase accident probability
- Peak accident times identified during specific hours
- Some road types show higher accident frequency
- Speed limit zones influence accident severity
## Conclusion
This Road Accident Analysis project successfully helped in understanding the major factors influencing road accidents such as weather conditions, road types, speed limits, and time of occurrence. Through data visualization, clear patterns and trends were identified which can help in improving road safety awareness and decision-making.

The analysis shows that accidents are not random but are influenced by specific conditions and time periods. These insights can be useful for traffic authorities and policymakers to take preventive measures and reduce accident rates in the future.
